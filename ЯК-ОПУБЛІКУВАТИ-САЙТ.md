# 🚀 Як опублікувати сайт Svit Academy — покрокова інструкція

Написано для людини, яка **раніше цього не робила**. Просто виконуй пункти по черзі.
Нічого не зламаєш — усі дії безпечні й безкоштовні.

Весь процес — це **3 великі етапи**:
1. Залити сайт на GitHub (сховище для файлів)
2. Підключити GitHub до Cloudflare Pages (щоб сайт з'явився в інтернеті)
3. Підключити домен `svitacademy.com`

Закладай на все ~1–2 години (більшість часу — це очікування, поки все «підхопиться»).

---

## 📦 ЕТАП 0. Що тобі знадобиться

- Комп'ютер, на якому лежить папка `svitacademy-website` (вона на Робочому столі, у папці «фото світ акедемі»).
- Пошта, до якої маєш доступ (для реєстрації).
- Доступ до налаштувань домену `svitacademy.com` (там, де ти його купувала / де зараз SendPulse).

## 🐙 ЕТАП 1. Заливаємо сайт на GitHub

### Крок 1.1 — Створити акаунт GitHub
1. Відкрий у браузері **https://github.com**
2. Натисни **Sign up** (Зареєструватися) угорі праворуч.
3. Введи пошту, придумай пароль і ім'я користувача (наприклад `svitacademy`).
4. Підтверди пошту (GitHub надішле лист із кодом).

✅ Готово, коли бачиш свою головну сторінку GitHub.

### Крок 1.2 — Встановити застосунок GitHub Desktop
> Це програма, яка заливає файли на GitHub **без жодних команд** — просто кнопками.

1. Відкрий **https://desktop.github.com**
2. Натисни **Download for macOS** (або Windows).
3. Встанови програму (як звичайний застосунок) і відкрий її.
4. У програмі натисни **Sign in to GitHub.com** і увійди тим акаунтом, що створила в кроці 1.1.
   - Браузер спитає «Authorize» — погодься.

✅ Готово, коли GitHub Desktop показує твоє ім'я.

### Крок 1.3 — Додати папку сайту в GitHub Desktop
1. У GitHub Desktop натисни зверху меню **File → Add Local Repository…**
   (або велику кнопку **Add an Existing Repository from your Hard Drive**).
2. Натисни **Choose…** і знайди папку:
   `Робочий стіл → фото світ акедемі → svitacademy-website`
3. Обери її й натисни **Add Repository**.
   - Якщо вискочить попередження «This directory does not appear to be a Git repository» — натисни синє посилання **create a repository** — і далі кнопку **Create Repository**.

✅ Готово, коли зліва бачиш список файлів сайту.

### Крок 1.4 — Опублікувати (залити на GitHub)
1. Унизу ліворуч, якщо є поле **Summary**, напиши будь-що, наприклад `Перший запуск сайту`, і натисни **Commit to main**.
2. Угорі натисни велику кнопку **Publish repository**.
3. У віконці:
   - **Name:** `svitacademy-website` (можна лишити як є)
   - **Keep this code private** — 🔲 **ЗНІМИ галочку** (щоб було Public — так простіше для Cloudflare). Хоча приватний теж підійде.
   - Натисни **Publish repository**.
4. Зачекай 1–3 хвилини, поки завантажаться всі фото.

✅ Готово! Твій сайт тепер на GitHub. Можеш перевірити: на github.com у розділі **Your repositories** з'явиться `svitacademy-website`.

> 💡 На майбутнє: коли я щось зміню в сайті, ти просто відкриваєш GitHub Desktop → **Commit to main** → **Push origin**, і сайт в інтернеті оновлюється сам.

## ☁️ ЕТАП 2. Підключаємо Cloudflare Pages

### Крок 2.1 — Створити акаунт Cloudflare
1. Відкрий **https://dash.cloudflare.com/sign-up**
2. Введи пошту й пароль, зареєструйся, підтверди пошту.

### Крок 2.2 — Створити проєкт Pages
1. Увійшовши, ліворуч знайди розділ **Workers & Pages** (або **Compute → Workers & Pages**).
2. Натисни **Create application** → вкладка **Pages** → **Connect to Git**.
3. Cloudflare попросить дозвіл до GitHub — натисни **Connect GitHub** і **Authorize**.
   - Можна дати доступ лише до репозиторію `svitacademy-website`.
4. У списку обери репозиторій **svitacademy-website** → **Begin setup**.

### Крок 2.3 — Налаштування збірки (ВАЖЛИВО, впиши точно так)
- **Project name:** `svitacademy` (буде в адресі, напр. `svitacademy.pages.dev`)
- **Production branch:** `main`
- **Framework preset:** `None` (нічого не обирай)
- **Build command:** *(залиш ПОРОЖНІМ — нічого не пиши)*
- **Build output directory:** впиши `/` (просто скісну риску) або лиши порожнім

Натисни **Save and Deploy**.

### Крок 2.4 — Зачекати й перевірити
1. Cloudflare почне «Deploying…» — зачекай 1–2 хвилини.
2. Коли з'явиться зелений напис **Success**, натисни на посилання виду
   **`https://svitacademy.pages.dev`** — і твій сайт відкриється в інтернеті! 🎉
3. Пройдись по сторінках і кнопках — усе має працювати.

✅ Сайт уже онлайн (поки що на технічній адресі `.pages.dev`).

## 🌐 ЕТАП 3. Підключаємо домен svitacademy.com

> Зараз `svitacademy.com` дивиться на старий сайт (SendPulse). Ми переведемо його на новий.

### Крок 3.1 — Додати домен у проєкт Pages
1. У Cloudflare відкрий свій проєкт **svitacademy** (Workers & Pages).
2. Вкладка **Custom domains** → **Set up a custom domain**.
3. Впиши `svitacademy.com` → **Continue**.
4. Cloudflare покаже, які записи (DNS) треба додати. **Не закривай це вікно** — знадобиться на наступному кроці.

### Крок 3.2 — Перевести домен на Cloudflare
Тут є два варіанти — обери свій:

**Варіант А (рекомендований Cloudflare): перенести весь домен у Cloudflare**
1. Cloudflare запропонує **Add site** — додай `svitacademy.com`, обери безкоштовний план (**Free**).
2. Cloudflare покаже **2 адреси серверів імен (nameservers)**, наприклад `xxx.ns.cloudflare.com`.
3. Зайди туди, де керуєш доменом (реєстратор, у якого купувала домен), знайди **Nameservers / DNS-сервери** і заміни їх на ці дві адреси Cloudflare.
4. Збережи. Зміна діє від 30 хвилин до 24 годин.

**Варіант Б (простіше, без перенесення): додати запис у поточного провайдера**
1. Зайди в налаштування DNS там, де зараз домен (SendPulse або реєстратор).
2. Додай запис, який показав Cloudflare у кроці 3.1 (зазвичай тип **CNAME** на `svitacademy.pages.dev`).
3. Збережи.

> Якщо не впевнена — напиши мені, який у тебе провайдер домену, і я підкажу точні кнопки для нього.

### Крок 3.3 — Відключити старий сайт SendPulse
1. У SendPulse (там, де зараз зроблений старий сайт) знайди прив'язку домену `svitacademy.com` і **відключи** її, щоб домен більше не вів на старий сайт.
2. Це важливо зробити, коли новий сайт уже відкривається на `svitacademy.com`.

### Крок 3.4 — Зачекати й перевірити
1. Через кілька годин відкрий **https://svitacademy.com** — має відкритися новий сайт.
2. Cloudflare сам видасть SSL-сертифікат (замочок 🔒 у браузері) — це автоматично.

✅ Готово! Сайт опубліковано на власному домені.
